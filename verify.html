🔍 Verify a Stamp

Verify any stamp trustlessly — directly against the MegaETH blockchain.
No account needed. Works even if TruthStamp is offline.

The file never leaves your device — we hash it locally and check the hash on-chain.

🛡️ Verify without TruthStamp

Even if TruthStamp disappears, you can verify any stamp using only public tools:

1

Hash your content

Use any SHA-256 tool. For text: emn178.github.io/online-tools/sha256
For files: sha256_checksum tool or run sha256sum yourfile.pdf in terminal.

2

Convert to bytes32

Prefix the hash with 0x if not already present. The result is your content fingerprint.

3

Call the smart contract

Open MegaETH explorer and call verifyStamp(bytes32 hash) on the contract:

Loading contract address...

Or use any Ethereum-compatible tool (ethers.js, cast, Remix) to call the contract directly with the RPC: https://carrot.megaeth.com/rpc

4

Read the result

The contract returns: { timestamp, creatorIdentity, proofId }
A non-zero timestamp proves the content existed at that moment, recorded immutably on-chain.
